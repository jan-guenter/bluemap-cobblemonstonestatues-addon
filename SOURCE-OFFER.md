# Corresponding source

Each binary artifact is accompanied alongside it by a version-matched
`-sources.jar`: under the same Maven coordinates when Maven-published, or on
the same Release otherwise. That sources artifact contains the complete
preferred form for modifying the MPL-2.0-covered
`BakedGeometryTopology.java`, including its attribution and modification
notice. For the production add-on it also contains the complete preferred form
of the LGPL-2.1-only adapter files listed in `LICENSES.md`. The repository below
supplies the corresponding build metadata needed to rebuild and relink the
Java add-on against a compatible BlueMap runtime.

The same Source Code Form is available in the project repository:
<https://github.com/jan-guenter/bluemap-cobblemonstonestatues-addon>.

The full unmodified Mozilla Public License 2.0 text is distributed as
`META-INF/licenses/MPL-2.0.txt` in both binary and sources artifacts. The
production binary and sources artifacts additionally distribute the full
unmodified GNU Lesser General Public License 2.1 text as
`META-INF/licenses/LGPL-2.1-only.txt`.
